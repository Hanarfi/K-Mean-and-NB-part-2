# Sistem Analisis Data Pasien Rawat Inap Anak

Aplikasi berbasis Streamlit untuk melakukan analisis data pasien rawat inap anak menggunakan metode:

- K-Means Clustering
- Naive Bayes Classification

## Fitur

- Login Multi Role
- Dashboard
- Upload Dataset
- Preprocessing
- K-Means
- Naive Bayes
- Evaluasi Model
- Riwayat Analisis
- Dashboard Pimpinan
- Export PDF
- Export Excel

## Teknologi

- Python
- Streamlit
- SQLite
- Scikit-learn
- Plotly
- Pandas
